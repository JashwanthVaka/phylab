# KINETIQ client modules

- `contentLoader.js`: cached API gateway and lesson retrieval.
- `router.js`: History API routes and deep links.
- `renderer.js`: safe reusable HTML primitives.
- `lessonEngine.js`: normalized JSON lesson renderer.
- `quiz.js`, `simulation.js`, `search.js`, `ui.js`: domain UI modules.
- `utils.js`: escaping, storage, progress, and utility helpers.
- `knowledgeGraph.js`: curriculum pathways and related-learning relationships.
- `flashcards.js`: generated revision cards and browser-local spaced repetition.
- `diagramEngine.js`: reusable accessible SVG physics diagrams.
- `graphEngine.js`: interactive SVG graph controls and PNG/SVG export.
- `calculatorEngine.js`: reusable calculators for core IBDP Physics domains.
